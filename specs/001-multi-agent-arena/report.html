Giai đoạnHạng mục Bàn giaoTiêu chí Nghiệm thu
Milestone 1
Core Engine & Vault		 packages/protocol, packages/core (SQLite WAL, JSONL Ledger, AES-256-GCM Vault, Council State Machine) + APIKeyAdapter + CLI cơ bản. Chạy thành công phiên Hội đồng 3 model qua CLI; 0% lộ secret; khóa kín vòng 1 (SC-002, SC-005).

MCP & ACP IDE Bridge		 mcp-arena-server (Streamable HTTP + stdio) & acp-bridge kết nối trực tiếp MSW Agent, VS Code, Cursor, Zed. Kết nối ≥ 3 Agent đa phương thức vào chung phòng trong < 3 phút (SC-001).
Milestone 3
Execution Mesh & Worktrees		 GitWorktreeManager, FileLeaseRegistry, ContextSlicer (≥ 50% giảm token) và cơ chế Ralph-Style Clean Retry. 2–5 Agent sửa code song song trên cùng repo với 0% xung đột hỏng nhánh gốc (SC-003, SC-004).
Milestone 4
Web Arena UI & A2A		 Giao diện trực quan apps/web-arena (Council Board, Critique Matrix, Human Gate) + liên thông /.well-known/agent.json. Trải nghiệm giám sát trực tiếp, bơm chỉ dẫn Steer giữa vòng và ký duyệt Human Gate.
